Tullius Widgets - user fonts / 사용자 글꼴

[한국어]
이 폴더에 글꼴마다 하위 폴더 하나를 만들면 설정 → 일반 → 글꼴 목록에 "사용자 글꼴: <이름>"이 표시됩니다.
  user-fonts/<글꼴 이름>/MyFont-Regular.ttf
  user-fonts/<글꼴 이름>/MyFont-Bold.ttf
- 인식하는 확장자는 TTF, OTF, WOFF2, WOFF입니다. 파일 이름의 Light, Regular, SemiBold, Bold 같은 표기로 굵기를 추정합니다. 이름에 Italic 또는 Oblique가 들어간 파일은 건너뜁니다.
- 클래식·컴팩트 HUD에 적용됩니다. 설정 창은 프리셋 글꼴을 사용합니다.
- 새 글꼴은 게임을 다시 시작하거나 세이브를 불러오면 목록에 나타납니다.
- 이름 규칙과 배포 방법 https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/user-fonts.md

[English]
Make one subfolder per font. It appears in Settings > General > Font Preset as "User font: <name>".
  user-fonts/<font name>/MyFont-Regular.ttf
  user-fonts/<font name>/MyFont-Bold.ttf
- Recognized extensions are TTF, OTF, WOFF2 and WOFF. Names such as Light, Regular, SemiBold and Bold determine the weight. Files named Italic or Oblique are skipped.
- User fonts apply to the classic and compact HUDs. Settings keep the preset font.
- New fonts show up after restarting the game or loading a save.
- Naming and sharing guide https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/user-fonts.md
