Tullius Widgets - icon packs / 아이콘 팩

[한국어]
이 폴더에 아이콘 팩 폴더를 넣으면 설정 → 일반 → 아이콘 스타일에 "아이콘 팩: <이름>"으로 나타납니다(컴팩트 HUD 전용).
  icon-packs/<팩 이름>/health.png, gold.png, slot-sword.png, slot-sword-left.png ...
  icon-packs/<팩 이름>/pack.json (선택) {"name": "표시 이름", "author": "제작자", "version": "1.0", "base": "dororong"}
- 파일 이름 목록과 제작 방법: https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/icon-packs.md
- 팩에 없는 아이콘은 기본 아이콘(base 테마)으로 보입니다. 일부만 바꾼 팩도 됩니다.
- 새 팩을 넣은 뒤에는 게임을 다시 시작하거나 세이브를 불러오면 목록에 나타납니다.

[English]
Put icon pack folders here; they appear in Settings > General > Icon Style as "Icon pack: <name>" (compact HUD only).
  icon-packs/<pack name>/health.png, gold.png, slot-sword.png, slot-sword-left.png ...
  icon-packs/<pack name>/pack.json (optional) {"name": "Display name", "author": "You", "version": "1.0", "base": "dororong"}
- Icon names and how to make a pack: https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/icon-packs.md
- Icons a pack lacks use the built-in ones of its base theme, so partial packs work.
- New packs show up after restarting the game or loading a save.
