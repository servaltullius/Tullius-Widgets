# Tullius Widgets v1.10.0

## 변경 요약
- **새 설정 창과 배치 편집 모드**
  - 설정 창이 바뀌었습니다. 왼쪽에 분류 목록이 있고 오른쪽에 넓은 본문이 있으며, 위젯과 겹치지 않는 쪽에 열립니다.
  - 예전 "일반" 탭은 **표시와 모양**과 **단축키와 언어**로 나뉘었습니다.
  - **배치 편집**을 누르면 설정 창이 접히고 화면 전체에서 위젯을 옮길 수 있습니다. 화면에는 얇은 편집 막대만 남고, 처음 쓸 때는 그림 안내가 나옵니다.
    - 위젯은 드래그해서 옮깁니다.
    - 마우스 휠은 선택한 위젯의 크기를, Shift+휠은 모든 위젯의 투명도를 바꿉니다.
    - "적용"을 누르면 바꾼 대로 남고, Esc를 누르면 위치와 크기가 편집 전으로 돌아갑니다.
  - 위젯을 고르면 옆에 **빠른 편집 카드**가 떠서 표시, 잠금, 크기, 위치, 표시 조건, 앞뒤 순서를 바로 바꿀 수 있습니다.
  - **Esc는 한 단계씩 물러납니다.** 열린 메뉴 → 위젯 선택 → 배치 편집 → 설정 창 순서입니다. 콘솔처럼 HUD를 가리는 메뉴의 Esc는 그 메뉴가 처리합니다.
  - 드롭다운 메뉴(글꼴, 아이콘 스타일, 표시 조건 등)를 키보드로 열고 고를 수 있습니다. ↓ ↑로 옮기고, Enter나 Space로 고르고, Esc로 닫습니다.
- **HUD 자동 숨김 (iHUD처럼)** (기본값은 꺼짐)
  - HUD가 사라져 있다가 다음 상황이 되면 다시 나타납니다.
    - 전투 중
    - 무기나 주문을 꺼냈을 때
    - 은신 중
    - 체력·매지카·지구력이 가득 차 있지 않을 때
    - 보이는 위젯의 값이 바뀔 때
  - 조건은 하나씩 끌 수 있고, 사라지기까지 기다리는 시간은 0~30초 사이로 정합니다.
- **자유 카메라에서 보일 것 선택:** 숨김(기존 동작), 체력·매지카·지구력만, 전부 중에서 고릅니다. SexLab·OStim 장면이나 콘솔 `tfc`에서 쓸 수 있습니다.
- **사용자 글꼴**
  - `Data/PrismaUI/views/TulliusWidgets/user-fonts/<글꼴 이름>/`에 TTF·OTF·WOFF2·WOFF 파일을 넣으면, 설정 → 표시와 모양 → 글꼴에서 HUD 글꼴로 고를 수 있습니다.
  - 안내: [docs/user-fonts.md](https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/user-fonts.md)
- **설정 파일 보호**
  - 저장된 설정을 읽지 못하면 화면 위쪽과 설정 창에 바로 안내가 뜹니다. 그 상태에서 아무것도 바꾸지 않으면 설정 파일은 그대로 남습니다.
  - 읽지 못한 파일 위에 새 설정이 저장되기 전에는, 예전 파일을 `TulliusWidgets.json.unloaded-<날짜-시각>.bak`로 따로 보관합니다. 게임을 켠 뒤 처음 저장할 때도 직전 파일을 `TulliusWidgets.json.prev`로 남깁니다.
  - 되돌리는 방법은 안내와 [README](https://github.com/servaltullius/Tullius-Widgets#설정-파일과-백업)에 있습니다.
- **수정**
  - 다른 모드가 손상된 메뉴 이름을 넘기면 로딩 화면 직후 게임이 꺼질 수 있던 문제(`TulliusWidgets.dll+429C6`)를 고쳤습니다.
  - 위젯을 가로로만 옮기면 게임을 다시 켰을 때 가로 위치가 돌아가던 문제를 고쳤습니다(v1.9.0부터 있던 문제).
  - 설정 창을 연 채 콘솔을 열었다 닫으면 마우스 커서가 사라지던 문제를 고쳤습니다.
  - 설정 파일의 저장 번호와 단축키를 읽는 방식을 고쳐, 아이콘 팩이나 글꼴 이름에 특정 단어가 들어가도 단축키가 잘못 잡히지 않습니다.

## 사용자 영향/호환성
- 기존 설정과 위젯 배치는 그대로 유지됩니다. 설정 파일 형식은 바뀌지 않았습니다.
- 메뉴 위치가 바뀌었습니다. 예전 "일반" 탭의 항목은 **표시와 모양**(HUD 스타일, 아이콘 스타일, 글꼴, 투명도 등)과 **단축키와 언어**에 있습니다.
- 예전 "전투 중에만 표시"와 "변할 때 표시"는 자동 숨김으로 옮겨집니다. 두 옵션을 같이 켜 두었다면, 이제는 둘 중 하나만 맞아도 HUD가 보입니다.
- 사용자 글꼴은 HUD에만 적용됩니다. 설정 창은 원래 글꼴을 유지합니다.
- 설정 파일 옆에 `.prev` 백업이 생깁니다. MO2를 쓰면 보통 `overwrite/SKSE/Plugins/` 폴더입니다.
- 게임 안 동작은 Skyrim 1.6.1170에서 확인했습니다.

## 설치/업데이트 안내
1. `v1.10.0` zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다. 아이콘 팩과 사용자 글꼴 폴더에 직접 넣은 파일은 지워지지 않습니다.
3. 게임을 완전히 종료한 뒤 다시 실행합니다.
