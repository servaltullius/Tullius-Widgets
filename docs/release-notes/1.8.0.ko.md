# Tullius Widgets v1.8.0 (초안)

## 변경 요약
- **컴팩트 HUD**를 새로 추가하고 신규 설치의 기본 스타일로 지정했습니다.
  - 카드 배경 없이 화면에 녹아드는 왼쪽 아래 계기형 배치입니다. 바닐라·TrueHUD·SkyHUD 자원 바 위 공간을 비워 둡니다.
  - 탐험 중에는 생활 정보(금화·무게·시계·날씨), 경험치 링, 장비 슬롯만 보이고, 전투 중이거나 값이 바뀌면 저항·전투 수치가 위로 펼쳐집니다.
  - 게임 안에서도 같은 글꼴로 보이도록 폰트(Pretendard, OFL)를 함께 배포합니다.
- **장비 슬롯 R / L / Z / P**
  - 무기 종류·주문 학파별 아이콘, 손별 공격력, 마법부여 충전률 바(20% 미만 경고색), 무기에 바른 독의 남은 횟수
  - 활·석궁 슬롯의 화살/볼트 보유 수
  - 포효 재사용 대기시간(남은 초와 회복 표시)과 배운/해금한 단어 수
  - 마지막으로 마신 물약과 남은 개수(0개면 붉은색)
  - 장비 이름 표시 방식: 항상 / 바꿀 때만(3초) / 숨김
- **지속 효과 목록 개선**: 분류 아이콘(체력·매지카·스태미나·속성 저항·방어·투명화·마비 등), 효과 크기, 정렬된 남은 시간, 해로운 효과 강조, 필터(해로운/이로운 효과만, 10분·1시간 넘는 긴 효과 숨김)
- **새 위젯**: 날씨(맑음/흐림/비/눈/실내), 최근 마신 물약, 누적 플레이 시간(기본 숨김)
- **항목별 표시 조건**: 위젯마다 항상 / 전투 중 / 값이 바뀔 때 / 전투 중 또는 값이 바뀔 때 중 선택
- 금화·경험치 증감(+120 등)을 값 위에 잠깐 표시합니다.
- 설정 패널이 열린 동안 배치 편집을 `Ctrl+Z` / `Ctrl+Y`로 되돌리거나 다시 실행할 수 있습니다.
- 컴팩트 묶음 위치 프리셋(왼쪽 아래/오른쪽 아래/왼쪽 위/오른쪽 위)과 배치 슬롯 3개(저장/불러오기)를 추가했습니다.
- 컴팩트 스타일에서는 효과가 없는 클래식 전용 설정(아이콘 스타일·색상 톤·배경 투명)을 숨기고, 투명도 슬라이더를 '슬롯 배경 진하기'로 표시합니다.
- 경험치 숫자 숨김 옵션을 추가했습니다.
- **단축키 변경**: 설정 → 일반에서 설정 패널 키(기본 Insert)와 위젯 전체 표시/숨김 키(기본 F11)를 F1~F12, Insert·Delete·Home·End·Page Up/Down, Pause·Scroll Lock, 숫자패드 중에서 바꿀 수 있습니다(콘솔·글자 입력 중에는 동작하지 않음). 온보딩 안내도 바꾼 키로 표시되며, 프리셋을 주고받아도 내 단축키는 바뀌지 않습니다.
- 화면비가 바뀌어도(21:9, 16:10 등) 위젯 묶음이 벌어지거나 화면 가운데에서 갈라지지 않도록 배치 전체 기준으로 위치를 계산합니다.
- "값 변화 시에만 표시"가 현실 시계·게임 시계·효과 타이머 때문에 계속 켜져 있던 문제와, 포효/파워 교체를 변화로 감지하지 못하던 문제를 고쳤습니다.
- 저자원 비네트를 가벼운 그라디언트로 바꾸고 카드의 블러를 제거해 Prisma UI 렌더링 부담을 줄였습니다.

## 사용자 영향/호환성
- 이전 버전에서 쓰던 설정은 **클래식 카드 스타일과 기존 배치·표시 항목을 그대로 유지**합니다. 설정 → 일반 → HUD 스타일에서 컴팩트로 바꾸면 컴팩트 기본 배치로 이동하며, 표시 여부는 유지됩니다.
- 새로 추가된 위젯(날씨, 최근 물약)은 기존 사용자에게 기본으로 숨겨져 있으며 설정에서 켤 수 있습니다.
- 클래식 스타일의 무기 카드에도 충전률·독 남은 횟수·탄약 수가 이름 아래 한 줄로 표시됩니다.
- 통계 데이터에 장비 종류·충전률·화살·포효 대기시간/단어·물약·날씨·효과 분류가 추가되었습니다. 구버전 플러그인과 섞여도 UI는 기본값으로 동작합니다.
- 릴리즈 zip이 폰트 포함으로 약 2MB 커졌습니다.

## 설치/업데이트 안내
1. `v1.8.0` zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 게임을 완전히 종료한 뒤 다시 실행합니다.
4. 컴팩트 HUD를 써 보려면 Insert → 일반 → HUD 스타일을 `컴팩트`로 바꿉니다.
