# Tullius Widgets v1.11.1

## 변경 요약
- 화면 오른쪽 끝 가까이 둔 위젯을 크게 키우면 화면 밖으로 넘치던 문제를 고쳤습니다.
  - 위젯이 키우기 전의 폭으로 줄을 나눈 뒤 커졌기 때문입니다. 그래서 지속 효과 목록의 배치 방향을 **가로**로 두면 오른쪽 카드가 화면 밖으로 잘렸습니다.
  - 4K 화면의 클래식 스타일에서는 가로로 둔 목록을 기본 자리에서 옮기지 않아도 화면 오른쪽을 넘었습니다.
  - 이제 커진 크기로 화면 안에 들어가도록 줄을 나눕니다. 오른쪽 끝 가까이에서 크기를 줄인 위젯은 남는 자리를 다 써서, 예전보다 한 줄에 더 많이 들어갑니다.
  - v1.11.0 이전부터 있던 문제입니다.

## 사용자 영향/호환성
- 설정 파일과 위젯 배치는 그대로 유지됩니다. 설정 파일 형식도 바뀌지 않았습니다.
- 오른쪽 끝에서 넘치던 목록은 이제 한 줄에 들어가는 카드 수가 줄어, 그만큼 아래(위로 쌓기면 위)로 길어집니다. 위로 쌓는 목록은 나침반 줄에 닿으면 넘치는 효과를 "+N"으로 셉니다.
- 게임 안 동작은 Skyrim 1.6.1170에서 확인했습니다.

## 설치/업데이트 안내
1. `v1.11.1` zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다. 아이콘 팩과 사용자 글꼴 폴더에 직접 넣은 파일은 지워지지 않습니다.
3. 게임을 완전히 종료한 뒤 다시 실행합니다.
