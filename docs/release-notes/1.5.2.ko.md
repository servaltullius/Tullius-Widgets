# Tullius Widgets v1.5.2

## 변경 요약
- `v1.5.2`는 `v1.5.1` 공개 이후 확인된 대화창 진입 시 HUD 아이콘이 계속 남아 있던 문제를 수정한 패치 릴리즈입니다.
  - Skyrim의 `Dialogue Menu`가 열릴 때 위젯 숨김 로직이 정확히 적용되도록 네이티브 메뉴 숨김 목록을 보강했습니다.
  - NPC 대화 진입 시 전투 HUD 아이콘이 화면에 남지 않도록 정리했습니다.
  - 관련 네이티브 계약 테스트를 추가해 이후 릴리즈에서 같은 누락이 다시 생기지 않도록 했습니다.

## 사용자 영향/호환성
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)과 호환됩니다.
- 이번 업데이트는 대화 UI 진입 중 HUD 가시성 보정이 중심이며, 설정 구조나 조작 방식은 바뀌지 않습니다.
- 저장 포맷과 전투 수치 계산 로직에는 변경이 없습니다.

## 설치/업데이트 안내
1. `v1.5.2` 정식 릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. `v1.5.1`을 사용 중이었다면 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산이 함께 새로 로드되도록 합니다.
4. 업데이트 후 NPC 대화창을 열었을 때 HUD 아이콘이 숨고, 대화를 닫으면 다시 정상 복귀하는지 확인합니다.
