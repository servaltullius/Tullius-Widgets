# Tullius Widgets v1.7.0-rc.1

## 변경 요약
- Skyrim 1.7.x 런타임(1.7.99 / 1.7.104)을 지원합니다.
  - SKSE 플러그인 기반 라이브러리(CommonLibSSE-NG)를 4.2.0에서 11.0.0으로 업데이트해 1.7의 새 Address Library 형식과 구조 변경을 반영했습니다.
  - 1.7.x에서 런타임 경고 배너가 표시되지 않도록 지원 런타임 판정을 갱신했습니다.
- 피해 감소율 계산을 바로잡았습니다.
  - 게임 엔진이 착용한 머리·몸통·손·발·방패 부위마다 더하는 숨은 3% 보너스를 반영합니다. 예: 방어도 361에 4부위를 착용하면 기존 43% → 실제 값 55%로 표시됩니다.
  - 최대 피해 감소율(80%)에 도달하는 방어도 안내도 착용 부위 보너스를 반영해 계산합니다.

## 사용자 영향/호환성
- 프리릴리즈입니다. 1.6.1170에서 게임 내 동작을 확인했으며, 1.7.x와 1.5.97은 빌드 검증만 마친 상태입니다. 1.7.x 또는 1.5.97에서 사용하신다면 동작 여부를 알려 주세요.
- 1.7.x에서 사용하려면 다음이 필요합니다.
  - Prisma UI 1.5.0 이상
  - Address Library for SKSE Plugins 최신 버전
  - 1.7.x용 SKSE64
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)과 위젯 배치는 그대로 유지됩니다. UI 디자인과 통계 데이터 형식에는 변경이 없습니다.
- 피해 감소율이 이전 버전보다 높게 표시될 수 있으며, 이는 실제 게임 계산에 맞춰진 정상 동작입니다.

## 설치/업데이트 안내
1. `v1.7.0-rc.1` 프리릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 1.7.x 사용자는 Prisma UI, Address Library, SKSE64를 1.7.x 대응 버전으로 함께 업데이트합니다.
4. 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산을 새로 로드합니다.
