# Tullius Widgets v1.8.1

## 변경 요약
- 체력·매지카·스태미나가 깎이면 실제보다 낮게 보이던 문제를 고쳤습니다.
  - 깎인 양이 두 번 계산되어, 예를 들어 스태미나 205에서 100을 쓰면 실제 105(51%) 대신 5(약 5%)로 보였습니다.
  - 그래서 달리기·회복 중 수치와 막대가 두 배 빠르게 움직였고, 낮은 자원 경고색(주황·빨강)도 너무 일찍 바뀌었습니다.
  - 이제 숫자와 막대가 게임(바닐라 HUD·STB)과 같은 값을 보여 줍니다. 클래식·컴팩트 스타일 모두 해당합니다.
- 컴팩트 HUD의 자원 막대가 갱신 간격에 맞춰 부드럽게 줄고 차오릅니다(전투 중 0.1초, 평상시 0.5초).

## 사용자 영향/호환성
- 설정 파일과 위젯 배치는 그대로 유지됩니다. 통계 데이터 형식도 바뀌지 않았습니다.
- v1.8.0을 쓰고 있다면 꼭 업데이트하세요. 그 이전 버전에도 같은 문제가 있었습니다.
- 게임 안 동작은 Skyrim 1.6.1170에서 확인했습니다.

## 설치/업데이트 안내
1. `v1.8.1` zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 게임을 완전히 종료한 뒤 다시 실행합니다.
