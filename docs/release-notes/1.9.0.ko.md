# Tullius Widgets v1.9.0

## 변경 요약
- **사용자 아이콘 팩**: 컴팩트 HUD의 아이콘을 직접 그린 PNG로 바꿀 수 있습니다.
  - `Data/PrismaUI/views/TulliusWidgets/icon-packs/<팩 이름>/`에 `health.png`, `gold.png`, `slot-sword.png` 같은 이름으로 그림을 넣으면 설정 → 일반 → 아이콘 스타일에 "아이콘 팩: <이름>"으로 나타납니다.
  - 넣은 아이콘만 바뀌고 나머지는 기본 아이콘으로 보이므로, 일부만 바꾼 팩도 됩니다.
  - `pack.json`으로 이름·제작자·버전과 기본 테마(`dororong` 또는 `standard`)를 정할 수 있습니다. 기본 테마가 배치와 아이콘 크기를 정하며, 같은 기본 테마끼리 바꾸면 내 위젯 배치가 그대로 유지됩니다.
  - 팩 폴더 이름에는 한글과 공백도 쓸 수 있습니다.
  - 만드는 법과 파일 이름 전체 목록: [docs/icon-packs.md](https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/icon-packs.md). 도로롱 아이콘 73종이 같은 이름 규칙이라 템플릿으로 쓸 수 있습니다.
- 배포 zip에 `icon-packs` 폴더와 안내 파일(`README.txt`)이 들어 있습니다.

## 사용자 영향/호환성
- 아이콘 팩은 컴팩트 HUD에만 적용됩니다. 클래식 카드 스타일은 바뀌지 않습니다.
- 기본 테마가 도로롱인 팩을 고르면 아이콘 스타일 설정도 도로롱 기준으로 바뀌어, 클래식 스타일로 돌아가면 도로롱 아이콘이 보입니다.
- 새 팩은 게임을 다시 시작하거나 세이브를 불러오면 목록에 나타납니다.
- MO2에서 팩만 든 압축을 설치하면 "<data>의 내용물이 유효하지 않은 것으로 보입니다" 경고가 뜰 수 있습니다. 경로가 `PrismaUI/views/TulliusWidgets/icon-packs/...`라면 그대로 확인을 누르면 됩니다.
- 기존 설정과 위젯 배치는 그대로 유지됩니다. 게임 안 동작은 Skyrim 1.6.1170에서 확인했습니다.

## 설치/업데이트 안내
1. `v1.9.0` zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 게임을 완전히 종료한 뒤 다시 실행합니다.
