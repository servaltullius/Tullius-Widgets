# Tullius Widgets v1.3.0-rc.1

## 변경 요약
- HUD 커스터마이즈가 이제 `그룹 단위`에서 `항목 단위`로 바뀝니다.
  - 레벨, 골드, 체력, 매지카, 스태미나, 저항, 공격력, 크리티컬 확률, 시간 표시 같은 항목을 각각 따로 배치할 수 있습니다.
  - 예전처럼 한 덩어리로 움직여야 했던 구성이 아니라, 원하는 항목만 골라 화면 곳곳에 따로 두는 식의 커스터마이즈가 가능합니다.
- 설정창을 연 상태에서 HUD를 직접 만지는 편집 흐름을 크게 다듬었습니다.
  - 위젯을 클릭해 선택하고, 바로 드래그로 이동하거나 핸들로 크기를 조절할 수 있습니다.
  - 선택된 위젯 기준으로 스냅/가이드가 보이도록 정리해 배치 맞추기가 쉬워졌습니다.
- 설정창 상단에 `선택 위젯 빠른 편집 카드`를 추가했습니다.
  - 표시/숨김
  - 크기 슬라이더
  - X/Y 미세 이동
  - 위치 초기화
  - 잠금
  - 앞으로 / 뒤로 순서 변경
- 숨김/잠금/정렬 순서 같은 편집 상태를 항목별 레이아웃에 함께 저장하도록 구조를 바꿨습니다.
  - 숨긴 위젯을 다시 켜도 이전 배치와 순서를 유지합니다.
  - 잠금된 위젯은 선택은 되지만 드래그/리사이즈는 막아 실수로 움직이는 일을 줄입니다.
- 기존 설정과 프리셋 호환 경로도 보강했습니다.
  - 예전 그룹 위치/크기 설정은 새 `itemLayouts` 기준으로 안전하게 해석되도록 마이그레이션됩니다.
  - 기존 표시 토글도 새 항목별 레이아웃 저장 구조에 맞춰 이어서 동작합니다.

## 사용자 영향/호환성
- 이번 RC는 **HUD 배치 방식이 크게 확장되는 업데이트**입니다.
  - 이전보다 커스터마이즈 자유도가 훨씬 높아졌지만, 실제 게임 해상도나 개인 취향에 따라 한 번 정도 재배치가 필요할 수 있습니다.
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)과 프리셋은 계속 읽을 수 있도록 하위 호환 경로를 유지합니다.
- 네이티브 DLL 쪽 신규 기능 추가보다는 Prisma UI 프런트엔드와 설정 모델 정리가 중심입니다.
  - 따라서 이번 변경의 핵심은 `HUD 편집 UX`와 `배치 저장 구조` 개선입니다.
- 이번 버전은 프리릴리즈(`rc`)이므로, 실사용 전 현재 설정 파일과 Data 폴더 백업을 권장합니다.

## 설치/업데이트 안내
1. `v1.3.0-rc.1` 프리릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산이 함께 새로 로드되도록 합니다.
4. 업데이트 후에는 설정창을 열고, 원하는 항목을 직접 클릭해 위치/크기/표시 상태가 기대대로 저장되는지 한 번 확인해 주세요.
