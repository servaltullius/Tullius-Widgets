# Tullius Widgets v1.4.0

## 변경 요약
- `v1.4.0`은 `v1.3.0` 이후 들어간 HUD 사용성 보강과 새 전투 슬롯 위젯을 묶은 정식 업데이트입니다.
  - 설정창을 드래그해서 옮기고 마지막 위치를 기억할 수 있습니다.
  - 해상도가 바뀌어도 기본 HUD 배치와 reset 위치가 현재 화면 크기에 맞게 다시 계산됩니다.
  - `포효/파워` 공용 슬롯 위젯이 추가되어 현재 선택된 샤우트 또는 파워를 HUD에 표시할 수 있습니다.

## 주요 기능 변화
- 설정창 사용성을 다듬었습니다.
  - 패널 헤더를 드래그해 원하는 위치로 옮길 수 있습니다.
  - 다시 열어도 마지막 위치를 기억하고, 화면이 작아지면 viewport 안으로 자동 보정됩니다.
  - 닫기 버튼, 탭, `전체 펼치기`/`전체 접기` 같은 상단 컨트롤의 텍스트 대비와 선명도를 높였습니다.
- 해상도 전환과 위치 초기화 동작을 보강했습니다.
  - FHD/UHD를 오갈 때 위젯 기본 배치와 scale이 현재 해상도 기준으로 자연스럽게 계산되도록 정리했습니다.
  - 위치 초기화 시에도 현재 화면 크기에 맞는 기본 위치로 돌아가도록 보강했습니다.
- `포효/파워` 공용 슬롯 위젯을 추가했습니다.
  - 현재 선택된 샤우트 또는 파워 이름을 장비/마법 계열 HUD와 같은 흐름으로 표시합니다.
  - 슬롯 변경 시 이전 이름이 겹쳐 남지 않도록 갱신 경로를 안정화했습니다.
  - 전용 도로롱 아이콘 자산을 적용해 다른 전투 위젯과 구분되도록 정리했습니다.
- 전투/효과 관련 자잘한 UI 문제도 함께 수정했습니다.
  - 장비/마법 위젯은 무기나 주문을 전환할 때 이전 이름이 남아 겹쳐 보이던 문제를 수정했습니다.
  - 지속 버프/디버프 배치 방향 셀렉트에서 `가로` 옵션이 잘리던 문제를 수정했습니다.
  - `가로` 배치가 실제 HUD에서 올바르게 펼쳐지도록 정리했습니다.
  - 소지 무게 `바만` 모드에서는 전체 트랙과 빈 구간이 더 또렷하게 읽히도록 가독성을 보강했습니다.

## 사용자 영향/호환성
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)은 계속 읽을 수 있도록 하위 호환 경로를 유지합니다.
- 해상도 대응 보강은 예전 레이아웃에도 적용되며, 실행 중 viewport 메타데이터를 저장하면서 점진적으로 안정화됩니다.
- 새 `포효/파워` 위젯은 기본적으로 비활성화 상태이며, 설정창에서 켜서 사용할 수 있습니다.
- 설정창 위치 기억은 로컬 UI 상태로 저장되며, 화면 밖으로 나간 위치는 자동으로 클램프됩니다.

## 설치/업데이트 안내
1. `v1.4.0` 정식 릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 기존 `v1.3.0` 또는 그 이전 버전을 사용 중이었다면 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산이 함께 새로 로드되도록 합니다.
4. 업데이트 후에는 설정창을 열어 `포효/파워` 위젯, 패널 위치 기억, 해상도 전환 후 reset 위치가 기대대로 동작하는지 한 번 확인해 주세요.
