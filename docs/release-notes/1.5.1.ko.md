# Tullius Widgets v1.5.1

## 변경 요약
- `v1.5.1`은 `v1.5.0` 공개 이후 확인된 HUD 아이콘 식별 배지 가시성 문제를 정리한 패치 릴리즈입니다.
  - 설정 패널을 닫았을 때 일부 HUD 아이콘의 작은 원형 식별 표시가 비어 보이던 문제를 수정했습니다.
  - 원형 배지의 대비와 글리프 가독성을 보강해 투명 HUD 배경에서도 식별이 더 안정적으로 보이도록 정리했습니다.
  - 관련 프론트엔드 회귀 테스트를 추가했습니다.

## 사용자 영향/호환성
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)과 호환됩니다.
- 이번 업데이트는 HUD 아이콘 배지의 시각 표현 보정이 중심이며, 설정 구조나 조작 방식은 바뀌지 않습니다.
- 네이티브 전투 계산 로직이나 저장 포맷 변경은 없습니다.

## 설치/업데이트 안내
1. `v1.5.1` 정식 릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. `v1.5.0`을 사용 중이었다면 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산이 함께 새로 로드되도록 합니다.
4. 업데이트 후 설정창을 닫은 상태에서 체력/매지카/스태미나 등 HUD 아이콘의 작은 원형 식별 표시가 또렷하게 보이는지 확인합니다.
