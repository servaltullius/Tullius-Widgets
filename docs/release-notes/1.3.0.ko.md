# Tullius Widgets v1.3.0

## 변경 요약
- `v1.3.0` 정식판은 HUD 편집 구조를 `그룹 단위`에서 `항목 단위` 중심으로 재정리한 버전입니다.
  - 레벨, 골드, 소지 무게, 체력/매지카/스태미나, 저항, 공격력, 시간, 지속 효과 같은 항목을 각각 따로 배치하고 숨김/잠금/정렬 순서까지 저장할 수 있습니다.
  - 선택 위젯 빠른 편집 카드와 직접 드래그 편집 흐름을 함께 다듬어, 설정창을 연 상태에서 바로 HUD를 조정하는 사용성이 안정적으로 유지되도록 정리했습니다.

## 정식 릴리즈 갱신 반영
- 정식 릴리즈 자산은 초기 `v1.3.0` 발행 이후 확인된 UI 이슈까지 반영해 다시 갱신했습니다.
  - 지속 버프/디버프 배치 방향 셀렉트 메뉴가 패널에서 잘려 `가로` 옵션이 제대로 보이지 않던 문제를 수정했습니다.
  - 지속 효과 `가로` 배치가 실제 HUD에서 오른쪽 화면 끝 기준으로 자연스럽게 펼쳐지도록 정리했습니다.
  - 소지 무게 `바만` 모드에서 현재 채움량은 보이지만 전체 한도 대비 얼마나 찼는지 읽기 어려웠던 점을 보강했습니다.
  - `바만` 모드에서는 전체 트랙 프레임, 빈 구간, 끝점 마커를 더 또렷하게 보여 주도록 조정했습니다.
  - 설정창은 헤더를 드래그해 옮길 수 있고, 마지막 위치를 기억하도록 바뀌었습니다.
  - 해상도를 바꿔도 설정창과 기본 HUD reset 위치가 현재 화면 크기에 맞게 다시 잡히도록 보강했습니다.
  - `포효/파워` 전용 슬롯 위젯을 추가해 현재 선택된 샤우트 또는 파워 이름을 HUD에 표시할 수 있습니다.
  - 포효/파워 위젯은 전용 도로롱 아이콘 자산과 remount 처리로, 교체 시 이름 겹침 없이 안정적으로 갱신되도록 정리했습니다.

## 주요 기능 변화
- 설정 패널과 HUD 표시 옵션을 크게 보강했습니다.
  - 4K 해상도에서 패널 전체가 비례 확대되도록 조정했습니다.
  - 소지 무게는 `숫자+바 / 숫자만 / 바만`, 저항력은 `실효값만 / 원본값만 / 둘 다`, 시간은 `날짜+시간 / 시간만`을 각각 선택할 수 있습니다.
  - 지속 버프/디버프는 가로/세로 배치 옵션이 실제 HUD에 반영되도록 정리했습니다.
- 성장 진행 위젯은 피드백을 반영해 `도로롱 아바타 + 외곽 XP 링 + 하단 레벨/경험치 텍스트` 구조로 다시 디자인했습니다.
  - 기존 분리형 레벨/경험치 인상보다 성장 상태가 더 직관적으로 읽히도록 만들었습니다.
  - 중앙 아이콘, 링 두께/색, 텍스트 위치를 실사용 기준으로 여러 차례 다듬어 현재 형태로 정리했습니다.
- 저항력 HUD는 가로형 일반 스탯 위젯에서 벗어나 `숫자 위 / 아이콘 아래`의 세로형 카드로 바뀌었습니다.
  - 화면 가로폭을 덜 차지하고, 표시 옵션 차이도 실제 HUD에서 더 분명하게 보이도록 정리했습니다.
- 해상도 전환 안정성도 보강했습니다.
  - FHD와 UHD를 오갈 때 위젯 위치뿐 아니라 크기까지 같은 상대 위치/비율로 유지되도록 저장 구조와 마이그레이션 경로를 정리했습니다.
  - 예전 레이아웃과 legacy fallback 경로도 startup 시 canonical `itemLayouts`로 승격되도록 보강했습니다.
- 정식판 마감 과정에서 구형 HUD 그룹 경로와 중복된 설정 패널 코드도 일부 정리해 이후 유지보수 리스크를 줄였습니다.

## 사용자 영향/호환성
- 이번 버전의 핵심은 `항목 단위 HUD 편집`, `표시 옵션 확장`, `경험치/저항력 위젯 리디자인`, `해상도 전환 대응`, `정식판 후속 UI 보정`입니다.
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)은 계속 읽을 수 있도록 하위 호환 경로를 유지합니다.
  - 예전 그룹 위치/크기와 fallback 레이아웃은 새 canonical `itemLayouts` 구조로 해석되거나 자동 승격됩니다.
  - 다만 HUD 편집 방식이 크게 확장된 업데이트라, 사용자 취향에 따라 한 번 정도 위치와 표시 상태를 다시 조정하는 편이 좋습니다.
- 저항력/소지 무게/시간/지속 효과처럼 표시 방식이 추가된 위젯은 기본값을 유지하면서 옵션만 확장했기 때문에, 업데이트 직후 HUD가 갑자기 크게 달라지지는 않습니다.
- 경험치 위젯은 기존보다 존재감이 커졌고, 피드백 반영을 위해 전용 아이콘 자산과 링 표현을 사용합니다.
- 해상도 전환 보정은 새 메타데이터가 저장된 이후부터 가장 안정적으로 동작합니다. 예전 설정을 쓰는 경우에도 실행 중 자동 보강 경로를 통해 self-heal 되도록 정리했습니다.

## 설치/업데이트 안내
1. `v1.3.0` 정식 릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 기존 `v1.3.0-rc.1` 또는 그 이전 RC를 사용 중이었다면 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산이 함께 새로 로드되도록 합니다.
4. 업데이트 후에는 설정창을 열어 원하는 HUD 항목의 위치, 크기, 표시 상태가 기대대로 유지되는지 한 번 확인해 주세요.
