# Tullius Widgets v1.5.0

## 변경 요약
- `v1.5.0`은 `v1.4.0` 이후 들어간 UI 가독성 확장과 위젯 배치 편의성 개선을 묶은 정식 업데이트입니다.
  - 설정창과 HUD 전체에 적용되는 폰트 프리셋 선택 기능이 추가되었습니다.
  - 선택된 위젯을 방향키와 `Shift+방향키`로 정밀 이동할 수 있습니다.
  - 키보드로 위젯을 움직일 때도 주변 위젯 정렬 가이드라인이 잠깐 표시됩니다.

## 주요 기능 변화
- 폰트 프리셋 기능을 추가했습니다.
  - 설정창 포함 UI 전체에 폰트 프리셋을 적용할 수 있습니다.
  - 기본, 가독성, 압축형, 고전형 프리셋을 제공해 취향과 언어별 가독성에 맞춰 선택할 수 있습니다.
  - HUD 본문과 설정창이 같은 프리셋 체계를 공유하도록 정리해, 다국어 번역을 사용할 때도 폰트 일관성이 유지됩니다.
- 위젯 배치 편의성을 키보드 기준으로 확장했습니다.
  - 선택된 위젯은 방향키로 `1px`, `Shift+방향키`로 `10px`씩 이동할 수 있습니다.
  - 마우스로 미세 조절하기 어려웠던 간격 맞추기와 열 정렬을 키보드만으로 더 쉽게 수행할 수 있습니다.
  - 입력창, 슬라이더, 셀렉트 포커스 중에는 키보드 이동이 개입하지 않도록 충돌을 막았습니다.
- 키보드 이동에도 정렬 가이드라인을 지원합니다.
  - 방향키로 위젯을 옮길 때 주변 위젯과 맞출 수 있는 선이 잠깐 표시됩니다.
  - 실제 위치는 스냅되지 않고, 기존 `1px / 10px` 이동 감각은 그대로 유지합니다.
  - 드래그 편집 때 쓰던 가이드 계산 기준을 그대로 재사용해 마우스와 키보드의 시각 언어를 맞췄습니다.

## 사용자 영향/호환성
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)은 계속 읽을 수 있도록 하위 호환을 유지합니다.
- 새 폰트 프리셋은 기본값이 `default`이며, 업데이트 후 즉시 기존 UI를 깨지 않도록 안전한 시스템 폴백 스택을 사용합니다.
- 키보드 위젯 이동과 가이드라인은 설정창을 열고 위젯을 선택한 상태에서만 동작합니다.
- 기존 마우스 드래그 편집과 설정창 quick edit 동작은 그대로 유지됩니다.

## 설치/업데이트 안내
1. `v1.5.0` 정식 릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 기존 `v1.4.0` 또는 그 이전 버전을 사용 중이었다면 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산이 함께 새로 로드되도록 합니다.
4. 업데이트 후에는 설정창을 열어 폰트 프리셋, 방향키 위젯 이동, 키보드 가이드라인이 기대대로 동작하는지 한 번 확인해 주세요.
