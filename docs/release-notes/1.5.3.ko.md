# Tullius Widgets v1.5.3

## 변경 요약
- HUD 아이콘 진입 장벽을 낮추기 위해 신규 설치의 기본 아이콘을 대중적인 심볼 아이콘으로 변경했습니다.
  - 도로롱 아이콘은 삭제하지 않고 일반 설정의 `아이콘 스타일`에서 다시 선택할 수 있습니다.
  - 도로롱 아이콘 위에 표시되는 작은 원형 보조 뱃지를 설정에서 켜거나 끌 수 있습니다.
- 경험치 진행 위젯의 아이콘에 적용되던 강제 가로 이동값을 제거해 원형 게이지 중앙에 정확히 맞도록 수정했습니다.
- 아이콘 설정 스키마를 v6으로 올리고 기존 사용자 외형을 보존하는 마이그레이션을 추가했습니다.

## 사용자 영향/호환성
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)과 호환됩니다.
- v1.5.2 이하 설정을 불러오면 기존 도로롱 아이콘과 보조 뱃지 표시 상태가 그대로 유지됩니다.
- 새 설정으로 시작하는 사용자는 일반 아이콘과 보조 뱃지 숨김 상태가 기본으로 적용됩니다.
- 전투 수치 계산, SKSE 플러그인 연동, 저장된 위젯 위치에는 변경이 없습니다.

## 설치/업데이트 안내
1. `v1.5.3` 정식 릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. `v1.5.2` 이하 버전을 사용 중이었다면 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산을 함께 새로 로드합니다.
4. 아이콘 스타일이나 보조 뱃지를 변경하려면 설정 패널의 `일반` 탭을 이용합니다.
