# Tullius Widgets v1.6.0

## 변경 요약
- HUD 전반을 절제된 노르딕 스타일로 개편했습니다.
  - 어두운 반투명 표면, 얇은 테두리, 정돈된 숫자 계층을 공통 디자인으로 적용했습니다.
  - 각 능력치의 의미에 맞는 색상을 아이콘 선, 테두리, 배경 틴트에 적용했습니다.
- 오른손·왼손 공격력과 장비 위젯이 서로 다른 표준 아이콘을 사용하도록 변경했습니다.
  - 공격력은 검 계열, 장비는 손 계열 아이콘으로 구분됩니다.
  - 도로롱 이미지 자산은 기존 테마 선택 시 그대로 유지됩니다.
- 경험치 위젯을 레벨 마크, 수치, 가로 진행 막대로 구성된 형태로 개편했습니다.
- 저항 위젯을 아이콘, 저항 이름, 유효 수치, 원본 수치가 한눈에 보이는 가로형으로 개편했습니다.
- 지속 효과 목록의 과도한 색상과 발광을 줄이고 디버프·긴급 상태만 의미색으로 강조했습니다.
- 신규 설치와 위치 초기화에 사용하는 기본 배치를 새 디자인에 맞게 재구성했습니다.
  - 화면에서는 정돈된 묶음처럼 배치되지만 각 위젯은 계속 독립적으로 이동, 크기 조절, 잠금, 표시 전환할 수 있습니다.

## 사용자 영향/호환성
- 기존 설정 파일(`Data/SKSE/Plugins/TulliusWidgets.json`)과 호환됩니다.
- 이미 저장된 개별 위젯 위치, 크기, 표시 여부, 잠금 상태와 투명 배경 설정은 유지됩니다.
- 새 설정으로 시작하거나 위치를 초기화하면 새 기본 배치와 불투명 위젯 표면이 적용됩니다.
- 기존 도로롱 아이콘 및 보조 뱃지 선택은 유지되며, 신규 설치의 기본 표준 아이콘 정책도 그대로입니다.
- 전투 수치 계산, SKSE 플러그인 통신, 통계 데이터 형식에는 변경이 없습니다.

## 설치/업데이트 안내
1. `v1.6.0` 정식 릴리즈 zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다.
3. 이전 버전을 사용 중이었다면 게임을 완전히 종료한 뒤 다시 실행해 DLL과 UI 자산을 함께 새로 로드합니다.
4. 새 기본 배치를 사용하려면 설정 패널에서 위젯 위치를 초기화합니다. 기존 배치를 유지하려면 별도 조작이 필요하지 않습니다.
