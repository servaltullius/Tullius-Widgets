# Tullius Widgets v1.11.0

## 변경 요약
- **지속 효과 목록 위로 쌓기**
  - 설정 → 효과·시간 → 쌓는 방향에서 **위로**를 고르면, 목록의 아래쪽 끝이 고정되고 효과가 늘수록 위로 자랍니다. 해로운 효과와 곧 끝나는 효과가 맨 아래에 옵니다.
  - 화면 아래쪽에 둔 목록이 효과가 많아져도 화면 밖으로 밀려나지 않습니다.
  - 위로 쌓는 목록은 화면 맨 위 나침반 줄 아래까지만 자라고, 넘치는 효과는 "+N"으로 셉니다.
  - 방향을 바꿔도 목록과 다른 위젯은 화면에서 제자리에 있습니다.
  - 위로 쌓을 때 기본 배치의 목록 자리
    - 컴팩트: 자원 막대 바로 위, 레벨 위젯 오른쪽
    - 클래식: 화면 위쪽(1080p 기준 아래쪽 끝 y=400)
  - 위로 쌓는 목록의 크기 조절 핸들은 오른쪽 위 모서리에 있습니다. 고정되는 왼쪽 아래 모서리의 맞은편입니다.
- **지난 날짜 위젯** (기본값은 꺼짐)
  - 게임을 시작한 뒤 며칠이 지났는지 보여 줍니다. 게임 통계의 Days Passed와 같은 값이며, 다 채우지 못한 하루는 세지 않습니다.
  - 설정 → 효과·시간의 시간 항목에서 켭니다. 클래식과 컴팩트, 표준·도로롱 아이콘을 모두 지원합니다. 아이콘 팩 파일 이름은 `daysPassed.png`입니다.
  - 표시 조건을 "값이 바뀔 때"로 두면 날짜가 바뀔 때 나타납니다.

## 사용자 영향/호환성
- 기존 설정과 위젯 배치는 그대로 유지됩니다. 쌓는 방향의 기본값은 지금처럼 **아래로**입니다.
- 설정 파일에 `timedEffects.growDirection` 항목이 더해집니다. 설정 파일 형식 번호는 그대로입니다.
- 예전 버전으로 되돌리기 전에는 쌓는 방향을 **아래로** 바꿔 두세요. 예전 버전은 이 항목을 모르고 목록의 저장된 자리를 위쪽 끝으로 읽으므로, 위로 쌓던 목록이 화면 아래로 밀려날 수 있습니다.
- 배치 슬롯은 쌓는 방향도 함께 저장합니다. 예전에 저장한 슬롯은 아래로 쌓기로 불러옵니다.
- 게임 안 동작은 Skyrim 1.6.1170에서 확인했습니다.

## 설치/업데이트 안내
1. `v1.11.0` zip을 다운로드합니다.
2. 압축 안의 `SKSE/`와 `PrismaUI/` 폴더를 게임의 `Data/` 폴더에 덮어씁니다. 아이콘 팩과 사용자 글꼴 폴더에 직접 넣은 파일은 지워지지 않습니다.
3. 게임을 완전히 종료한 뒤 다시 실행합니다.
