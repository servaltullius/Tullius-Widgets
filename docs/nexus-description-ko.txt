[size=4][b]Tullius Widgets[/b][/size]

[url=https://www.nexusmods.com/skyrimspecialedition/mods/148718]Prisma UI[/url] 기반의 Skyrim SE/AE 현대식 전투 HUD이자 STB Widgets 대체 모드입니다.
v1.8.0부터 카드 없이 화면에 녹아드는 [b]컴팩트 HUD[/b]가 신규 설치 기본값이며, 기존 카드형 클래식 스타일도 그대로 쓸 수 있습니다.
모든 위젯은 서로 독립적으로 이동하고 설정할 수 있습니다. 표준 아이콘이 기본이고, 도로롱 아이콘 테마도 고를 수 있습니다.

[size=3][b]v1.9.0 새 기능: 아이콘 팩[/b][/size]

[list]
[*]컴팩트 HUD 아이콘을 직접 그린 PNG로 바꿀 수 있습니다. [font=Courier New]PrismaUI/views/TulliusWidgets/icon-packs/<팩 이름>/[/font]에 [font=Courier New]health.png[/font], [font=Courier New]slot-sword.png[/font] 같은 이름으로 넣으면 설정 → 일반 → 아이콘 스타일에 나타납니다
[*]넣은 아이콘만 바뀌고 나머지는 기본 아이콘으로 보여, 일부만 바꾼 팩도 됩니다. 팩만 따로 모드로 배포할 수도 있습니다
[*]만드는 법과 파일 이름 목록: [url=https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/icon-packs.md]아이콘 팩 가이드[/url]
[/list]

[size=3][b]v1.8.0 주요 변경점[/b][/size]

[list]
[*][b]컴팩트 HUD[/b]: 왼쪽 아래 계기형 배치. 바닐라·TrueHUD·SkyHUD 자원 바 위 공간을 비워 둡니다
[*][b]장비 슬롯 R / L / Z / P[/b]: 무기 종류·주문 학파 아이콘과 손별 공격력, 마법부여 충전, 무기에 바른 독의 남은 횟수, 화살·볼트 수, 포효 재사용 대기시간과 단어 수, 마지막으로 마신 물약
[*][b]새 위젯[/b]: 날씨(맑음/흐림/비/눈/실내), 누적 플레이 시간
[*][b]지속 효과 목록[/b]: 분류 아이콘, 효과 크기, 해로운 효과 강조, 필터
[*][b]위젯별 표시 조건[/b]: 항상 / 전투 중 / 값이 바뀔 때
[*]묶음 위치 프리셋 4곳과 크기 4단계, 배치 슬롯 3개, 배치 편집 되돌리기([b]Ctrl+Z[/b] / [b]Ctrl+Y[/b])
[*]설정 패널 키와 위젯 표시 키 변경
[*]컴팩트용 [b]미니 도로롱 아이콘 73종[/b](비공식 팬아트)
[*]게임 안에서도 같은 글꼴로 보이도록 Pretendard 폰트 동봉
[*]화면 가장자리 시각 알림(비네트) 제거
[*]Skyrim 1.7.x 지원, 피해 감소율 계산을 게임과 같게 수정
[*]기존 사용자의 설정은 클래식 스타일과 배치를 그대로 유지합니다. 설정 → 일반 → HUD 스타일에서 컴팩트로 바꿀 수 있습니다
[/list]

[size=3][b]핵심 기능[/b][/size]

[list]
[*]성장, 플레이어, 저항, 방어, 공격, 장비, 시간·날씨, 이동, 지속 효과를 다루는 [b]28개 독립 HUD 항목[/b]
[*][b]컴팩트 HUD[/b]와 [b]클래식 카드[/b] 두 가지 스타일
[*]직접 그린 PNG로 컴팩트 HUD 아이콘을 바꾸는 [b]아이콘 팩[/b]
[*]알아보기 쉬운 [b]표준 아이콘이 기본값[/b]이며, 도로롱 테마와 선택형 식별 뱃지도 지원
[*]위젯별 [b]이동, 크기 조절, 잠금, 표시/숨김, 앞뒤 순서[/b]와 [b]표시 조건[/b] 설정
[*]직접 드래그, 이웃 위젯 스냅, 정렬 가이드, 방향키 1px/10px 이동, 편집 되돌리기
[*]전체 투명도, HUD 폰트 설정. 클래식 스타일은 색상 톤과 배경 투명도 조절
[*][b]프리셋 내보내기/가져오기[/b]와 배치 슬롯 3개
[*]설정 패널 키와 위젯 표시 키 변경(콘솔·글자 입력 중에는 반응하지 않음)
[*]런타임/SKSE/Address Library 조합 이상 시 [b]경고 배너[/b] 표시
[*][b]외부 JSON 다국어[/b] 지원. 기본 한국어/영어 포함
[/list]

[size=3][b]표시 항목[/b][/size]

[list]
[*][b]성장 / 플레이어 정보[/b] - 경험치 진행도, 레벨, 골드, 소지 무게, 체력, 매지카, 스태미나
[*][b]저항력[/b] - 마법, 화염, 냉기, 전기, 독, 질병
[*][b]방어[/b] - 방어도, 피해 감소율
[*][b]공격[/b] - 오른손/왼손 공격력, 치명타 확률
[*][b]장착 슬롯[/b] - 오른손/왼손 장비(충전·독·화살), 포효/파워(재사용 대기시간·단어), 최근 마신 물약
[*][b]이동[/b] - 이동 속도
[*][b]시간[/b] - 스카이림 날짜/시간, 현실 날짜/시간, 날씨, 누적 플레이 시간
[*][b]지속 효과[/b] - 분류 아이콘, 효과명과 크기, 남은 시간, 필터
[/list]

[size=3][b]표시값 관련 참고[/b][/size]

[list]
[*]치명타 확률은 [b]0% ~ 100%[/b] 범위로 안전하게 표시됩니다
[*]마법/화염/냉기/전기/독 저항은 [b]85% 상한[/b]을 고려한 실효값 기준으로 안내됩니다
[*]질병 저항은 [b]0% ~ 100%[/b] 범위로 표시됩니다
[*]필요한 항목은 원본값과 실효값을 분리해서 보여줍니다
[/list]

[size=3][b]설치 방법[/b][/size]

[b]수동 설치:[/b] 압축 파일 내용을 [font=Courier New]Skyrim Special Edition/Data/[/font] 폴더에 복사합니다.

[b]설치 후 구조:[/b]
[code]
Data/
  SKSE/Plugins/TulliusWidgets.dll
  PrismaUI/views/TulliusWidgets/index.html
  PrismaUI/views/TulliusWidgets/i18n/manifest.json
  PrismaUI/views/TulliusWidgets/i18n/en.json
  PrismaUI/views/TulliusWidgets/i18n/ko.json
  PrismaUI/views/TulliusWidgets/assets/...
  PrismaUI/views/TulliusWidgets/fonts/...
[/code]

[line]

[size=3][b]조작 키[/b][/size]
[list]
[*][b]Insert[/b] - 설정 패널 열기/닫기(설정에서 변경 가능)
[*][b]F11[/b] - 위젯 전체 표시/숨김(설정에서 변경 가능)
[*][b]ESC[/b] - 설정 패널 닫기
[*][b]드래그/리사이즈[/b] - 설정 패널이 열린 동안 위젯 편집
[*][b]방향키[/b] - 선택한 위젯을 1px 이동
[*][b]Shift + 방향키[/b] - 선택한 위젯을 10px 이동
[*][b]Ctrl + Z[/b] / [b]Ctrl + Y[/b] - 설정 패널이 열린 동안 배치 편집 되돌리기 / 다시 실행
[/list]

[line]

[size=3][b]다국어 / 번역[/b][/size]

이 모드는 [b]외부 JSON 언어 파일[/b]을 지원합니다.
[b]새 언어 추가를 위해 DLL을 수정할 필요는 없습니다.[/b]

[b]기본 포함 언어:[/b]
[list]
[*]한국어
[*]영어
[/list]

[b]언어 파일 위치:[/b]
[code]
Data/PrismaUI/views/TulliusWidgets/i18n/
  manifest.json
  en.json
  ko.json
[/code]

[b]새 언어 추가 방법:[/b]
[list]
[*][font=Courier New]en.json[/font]을 복사해 [font=Courier New]fr.json[/font] 같은 새 파일을 만듭니다
[*]JSON 값들을 원하는 언어로 번역합니다
[*][font=Courier New]manifest.json[/font]의 [font=Courier New]languages[/font] 배열에 새 언어 항목을 추가합니다
[*]필요하면 [font=Courier New]locale[/font] 값을 넣어 현실 날짜/시간 포맷을 해당 언어/지역에 맞춥니다
[*]게임 내 설정 패널의 [b]Language[/b] 드롭다운에서 선택합니다
[/list]

[b]manifest 항목 예시:[/b]
[code]
{
  "code": "fr",
  "label": "Français",
  "file": "fr.json",
  "locale": "fr-FR"
}
[/code]

일부 번역 키가 비어 있거나 누락돼도 UI가 깨지지 않고 [b]기본 영어 문자열[/b]로 fallback 됩니다.
