[size=4][b]Tullius Widgets[/b][/size]

[url=https://www.nexusmods.com/skyrimspecialedition/mods/148718]Prisma UI[/url] 기반의 Skyrim SE/AE 현대식 전투 HUD이자 STB Widgets 대체 모드입니다.
전투와 탐험 중 확인하는 25개 항목을 절제된 노르딕 스타일로 표시하면서도, 모든 위젯을 서로 독립적으로 이동하고 설정할 수 있습니다.
신규 설치에서는 알아보기 쉬운 표준 아이콘이 기본이며, 기존 도로롱 아이콘 테마도 선택해서 사용할 수 있습니다.

[size=3][b]v1.6.0 주요 변경점[/b][/size]

[list]
[*]어두운 반투명 표면, 얇은 테두리, 정돈된 숫자 계층과 능력치별 의미색으로 HUD 전면 개편
[*][b]모든 위젯의 독립성 유지[/b]: 항목별 이동, 크기 조절, 잠금, 표시/숨김, 앞뒤 순서 변경 가능
[*]대중적인 표준 아이콘을 기본값으로 변경. 도로롱 아이콘은 선택 가능하며 식별 뱃지는 완전히 비활성화 가능
[*]경험치를 레벨 마크, 수치, 가로 진행 막대로 구성된 위젯으로 개편
[*]저항 위젯을 실효값과 원본값이 함께 보이는 가로형으로 개편
[*]공격력과 장비 위젯을 검/손 아이콘으로 명확히 구분
[/list]

[line]

[size=3][b]핵심 기능[/b][/size]

[list]
[*]성장, 플레이어, 저항, 방어, 공격, 장착, 시간, 이동, 지속 효과를 포함한 [b]25개 독립 HUD 항목[/b] 표시
[*]알아보기 쉬운 [b]표준 아이콘이 기본값[/b]이며, 기존 도로롱 테마와 선택형 식별 뱃지도 지원
[*]위젯별 [b]이동, 크기 조절, 잠금, 표시/숨김, 앞뒤 순서[/b] 설정
[*]직접 드래그, 이웃 위젯 스냅, 정렬 가이드, 방향키 1px/10px 이동 지원
[*][b]전투 중에만[/b], [b]값 변화 시에만 표시[/b] 같은 표시 모드 지원
[*]전체 투명도, HUD 폰트, 색상 톤, 배경 투명 조절 지원
[*][b]프리셋 내보내기/가져오기[/b] 지원
[*]체력/매지카/스태미나 부족 및 과적재 시 [b]비네트 시각 경고[/b] 표시
[*]런타임/SKSE/Address Library 조합 이상 시 [b]경고 배너[/b] 표시
[*][b]외부 JSON 다국어[/b] 지원. 기본 한국어/영어 포함
[/list]

[size=3][b]표시 항목[/b][/size]

[list]
[*][b]성장 / 플레이어 정보[/b] - 경험치 진행도, 레벨, 골드, 소지 무게, 체력, 매지카, 스태미나
[*][b]저항력[/b] - 마법, 화염, 냉기, 전기, 독, 질병
[*][b]방어[/b] - 방어도, 피해 감소율
[*][b]공격[/b] - 오른손/왼손 공격력, 치명타 확률
[*][b]장착 슬롯[/b] - 오른손/왼손 장비와 선택된 포효/파워
[*][b]이동[/b] - 이동 속도
[*][b]시간[/b] - 스카이림 날짜/시간, 현실 날짜/시간
[*][b]지속 효과[/b] - 소스명, 효과명, 남은 시간
[/list]

[size=3][b]표시값 관련 참고[/b][/size]

[list]
[*]치명타 확률은 [b]0% ~ 100%[/b] 범위로 안전하게 표시됩니다
[*]마법/화염/냉기/전기/독 저항은 [b]85% 상한[/b]을 고려한 실효값 기준으로 안내됩니다
[*]질병 저항은 [b]0% ~ 100%[/b] 범위로 표시됩니다
[*]필요한 항목은 원본값과 실효값을 분리해서 보여줍니다
[/list]

[size=3][b]설치 방법[/b][/size]

[b]수동 설치:[/b] 압축 파일 내용을 [font=Courier New]Skyrim Special Edition/Data/[/font] 폴더에 복사합니다.

[b]설치 후 구조:[/b]
[code]
Data/
  SKSE/Plugins/TulliusWidgets.dll
  PrismaUI/views/TulliusWidgets/index.html
  PrismaUI/views/TulliusWidgets/i18n/manifest.json
  PrismaUI/views/TulliusWidgets/i18n/en.json
  PrismaUI/views/TulliusWidgets/i18n/ko.json
  PrismaUI/views/TulliusWidgets/assets/...
[/code]

[line]

[size=3][b]조작 키[/b][/size]
[list]
[*][b]Insert[/b] - 설정 패널 열기/닫기
[*][b]F11[/b] - 위젯 전체 표시/숨김
[*][b]ESC[/b] - 설정 패널 닫기
[*][b]드래그/리사이즈[/b] - 설정 패널이 열린 동안 위젯 편집
[*][b]방향키[/b] - 선택한 위젯을 1px 이동
[*][b]Shift + 방향키[/b] - 선택한 위젯을 10px 이동
[/list]

[line]

[size=3][b]다국어 / 번역[/b][/size]

이 모드는 [b]외부 JSON 언어 파일[/b]을 지원합니다.
[b]새 언어 추가를 위해 DLL을 수정할 필요는 없습니다.[/b]

[b]기본 포함 언어:[/b]
[list]
[*]한국어
[*]영어
[/list]

[b]언어 파일 위치:[/b]
[code]
Data/PrismaUI/views/TulliusWidgets/i18n/
  manifest.json
  en.json
  ko.json
[/code]

[b]새 언어 추가 방법:[/b]
[list]
[*][font=Courier New]en.json[/font]을 복사해 [font=Courier New]fr.json[/font] 같은 새 파일을 만듭니다
[*]JSON 값들을 원하는 언어로 번역합니다
[*][font=Courier New]manifest.json[/font]의 [font=Courier New]languages[/font] 배열에 새 언어 항목을 추가합니다
[*]필요하면 [font=Courier New]locale[/font] 값을 넣어 현실 날짜/시간 포맷을 해당 언어/지역에 맞춥니다
[*]게임 내 설정 패널의 [b]Language[/b] 드롭다운에서 선택합니다
[/list]

[b]manifest 항목 예시:[/b]
[code]
{
  "code": "fr",
  "label": "Français",
  "file": "fr.json",
  "locale": "fr-FR"
}
[/code]

일부 번역 키가 비어 있거나 누락돼도 UI가 깨지지 않고 [b]기본 영어 문자열[/b]로 fallback 됩니다.
