# v1.5.1 Patch Release Plan

## Goal
- 공개된 `v1.5.0` 이후 발견된 HUD 아이콘 식별 배지 가시성 문제를 `v1.5.1` 패치 릴리즈로 배포한다.

## Non-Goals
- 추가 기능 포함
- 네이티브 플러그인 동작 변경
- 릴리즈 메타데이터(`meta.ini`) 수동 수정

## Affected Files
- `view/src/components/StatWidget.tsx`
- `view/src/components/StatWidget.test.tsx`
- `xmake.lua`
- `docs/release-notes/1.5.1.ko.md`

## Constraints
- WSL에서 네이티브 빌드는 직접 `xmake` 호출 대신 공식 스크립트/Windows 경유 엔트리포인트를 사용한다.
- GitHub 릴리즈 publish는 `scripts/release-local.ps1`를 우선 사용한다.
- 기존 공개 버전이 있으므로 semantic versioning 기준 `patch`만 올린다.

## Milestones
- [ ] `1.5.1` 버전과 릴리즈 노트를 반영한다.
- [ ] 프론트엔드 검증과 패키지 산출물을 생성한다.
- [ ] 수정 커밋과 릴리즈 준비 커밋을 만들고 원격에 푸시한다.
- [ ] `v1.5.1` 태그를 생성해 원격에 푸시한다.
- [ ] GitHub 정식 릴리즈를 publish하고 결과를 확인한다.

## Validation
- `cd view && npm run lint`
- `cd view && npm run test`
- `cd view && npm run build`
- `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<release-local.ps1>" -NoPublish`

## Risks / Rollback
- 릴리즈 publish 실패 시 태그와 release 상태를 먼저 확인하고, 이미 생성된 release가 있으면 asset upload/edit로 복구한다.
- 버전 반영 후 문제가 발견되면 `v1.5.1` 태그 전까지는 로컬 수정으로 정리하고, 태그 이후면 후속 `v1.5.2` 패치로 수정한다.
