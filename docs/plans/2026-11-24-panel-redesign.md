# 설정 패널 새 디자인 (2026-11-24)

> 대체됨: 같은 날 사용자 결정으로 `2026-11-24-settings-window-layout-mode.md`(설정 창 + 배치 편집 모드)로 바뀌었다. 토큰·컨트롤·Esc 소유 알림 결정은 그 문서가 이어 쓴다.

## 배경과 결정
- 사용자 요청: 오래전에 만든 설정 패널이 투박하다. 새로 만들고 싶다.
- 현재 상태(브라우저 1080p 캡처로 확인): 패널이 화면 폭을 거의 다 차지해 HUD를 가리고, 글자 크기(16~36px)·색(노란 #ffd700, 파란 기본 슬라이더)·컨트롤 모양이 제각각이며, 안내문이 한 줄로 길게 늘어진다. 스타일은 컴포넌트마다 인라인으로 흩어져 있다.
- 사용자 선택(2026-11-24): 시안 A "서랍". 화면 한쪽에 붙는 폭 520px(1080p 기준) 패널, 위쪽 탭 4개. HUD가 오른쪽이면 왼쪽에 붙는다.
- 시안: `.playwright-mcp/mockups/a.html`, `a2.html`(로컬, 커밋 안 함).

## 디자인 토큰 (컴팩트 HUD와 같은 계열)
- 바탕 `rgba(17,15,12,0.94)`, 올린 면 `#1c1914`, 우물(입력칸) `#0d0c0a`, 선 `rgba(236,231,219,0.10)`/진한 선 `0.18`.
- 글자 `#ece7db`, 보조 `#b8b1a3`, 흐림 `#8a8375`. 금색 `#d2bb83`은 켜짐·선택·현재 탭에만. 경고 `#e6b866`, 위험 `#e8786d`, 성공 `#a3c994`.
- 글꼴: 동봉 Pretendard(`"Tullius Pretendard"`). 크기(1080p): 제목 22/600, 탭 15, 항목 16/500, 하위 항목 15/400, 묶음 제목 13/600 보조색, 안내 13 흐림색. 패널 배율(`resolvePanelScale`, 1~1.6)은 CSS 변수 `--ps`로 곱한다.
- 모서리 8px(컨트롤), 패널은 화면 끝에 붙으므로 모서리 없음. 그림자·흐림 효과 없음(Ultralight 안전).

## 레이아웃
```
┌ 서랍 (폭 520*ps, 높이 100vh) ─────────┐
│ 툴리우스 위젯   [반대쪽에 붙이기] [닫기 Esc] │
│ 일반  위젯  효과·시간  배치  (금색 밑줄)     │
├─────────────────────────────────────────┤
│ (선택한 위젯 빠른 편집 카드 - 있을 때)      │
│ 묶음 제목            [모두 펼치기/접기]      │
│ 항목 이름                          [컨트롤] │
│ 안내문(두 줄 이내)                          │
│ ─ 구분선 ─                                │
│ ... (본문만 세로 스크롤)                    │
├─────────────────────────────────────────┤
│ 위젯을 끌어 옮길 수 있습니다                │
└─────────────────────────────────────────┘
```
- 탭 id는 그대로(`general/combat/effects/presets`), 표시 이름만 "일반 / 위젯 / 효과·시간 / 배치".
- 항목은 카드 대신 구분선으로 나눈 행. 라벨 왼쪽, 컨트롤 오른쪽 정렬.
- 섹션(아코디언)은 묶음 제목 + 접기 화살표로 바꾼다(카드·노란 배경 없음). 펼침 상태 저장은 그대로.
- 일반 탭은 "표시 / 모양 / 언어와 단축키" 세 묶음으로 나눈다(항목은 그대로, 순서만 정리).

## 붙는 쪽(도킹)
- 저장값 `panelDock: 'auto' | 'left' | 'right'`(localStorage, 기존 패널 위치 저장과 같은 방식). 기본 `auto`.
- auto 규칙: 컴팩트 HUD면 `compactAnchor`가 오른쪽(bottomRight/topRight)일 때 왼쪽, 아니면 오른쪽. 클래식이면 보이는 위젯들 가운데 x의 평균이 화면 가운데보다 오른쪽이면 왼쪽, 아니면 오른쪽.
- 헤더 버튼 "왼쪽에 붙이기/오른쪽에 붙이기"를 누르면 그 쪽으로 고정(left/right)한다.
- 기존 "패널 끌어 옮기기"(자유 위치)는 없앤다. 저장된 옛 위치 값은 읽지 않는다(지우지 않아도 무해).

## 컨트롤
- `Toggle`: 숨긴 `<input type=checkbox>`를 품은 `<label>` + 스위치 모양(켜면 금색). 키보드 포커스 표시. 선택적 `help` 문구.
- `SelectRow`/`CustomSelect`: 모양만 새로(우물 배경, 진한 선, 메뉴는 올린 면). 선택지가 3개 이하이고 짧으면 `variant="segmented"`로 버튼을 나란히(HUD 스타일, 자유 카메라, 효과 목록 방향 등). 세그먼트도 `data-testid={testId}`와 `${testId}-option-${value}`를 유지한다.
- `SliderRow`(새): 라벨 + 금색 트랙 range + 값 표시. 흩어진 인라인 range를 모두 이것으로.
- 버튼: `primary`(금색 테두리)·기본 두 가지만.
- 기존 인라인 스타일과 `ui-theme.css`의 패널용 변수(노란 #ffd700 계열)는 새 `panel.css`로 대체. 온보딩·경고 배너는 이번 범위 밖(색만 새 토큰으로 맞출 수 있으면 맞춤).

## 지켜야 할 기존 동작
- 모든 설정 경로·저장 동작, 테스트가 쓰는 `data-testid`, 탭·섹션 펼침 상태 저장, 선택 위젯 빠른 편집 카드의 동작, Esc 닫기, 단축키 캡처, 프리셋 내보내기/가져오기, 배치 슬롯.
- 설정 창 포커스·자동 숨김·자유 카메라 동작(이전 기능)과 사용자 글꼴(설정 창은 프리셋 글꼴 유지).
- 패널 바깥(HUD 영역)은 지금처럼 클릭이 통과해 위젯을 끌 수 있어야 한다.

## Codex 계획 검토 반영 (2026-11-24, packet 모드) — 위 본문보다 우선
- 도킹 시점: auto 방향은 **패널을 열 때 한 번** 계산하고 닫을 때까지 유지한다(위젯을 끄는 도중 서랍이 반대쪽으로 튀지 않게). 사용자가 직접 바꾸면 즉시 이동.
- auto로 돌아가는 길: 헤더 버튼은 반대쪽으로 고정(left/right). 일반 탭 "언어와 단축키" 묶음에 "설정 창 위치: 자동 / 왼쪽 / 오른쪽" 세그먼트를 두어 auto로 되돌릴 수 있게 한다.
- 클래식 auto 규칙: 평균 x 대신 **실제 위젯 사각형(측정값)과 좌우 서랍 영역(폭 = 실제 서랍 폭)의 겹침 면적**을 비교해 덜 가리는 쪽에 붙는다. 위젯이 없거나 측정할 수 없거나 동률이면 오른쪽. 컴팩트는 앵커 규칙.
- 서랍 폭: `min(520px × ps, 46vw)`(720p에서 화면의 절반 가까이 가리지 않게). 실제 가림 폭 = 테두리 포함 바깥 폭.
- 패널 글꼴: 패널과 선택 메뉴는 `--tw-font-ui`(프리셋)를 쓴다. 기본 프리셋의 UI 글꼴 스택 맨 앞에 동봉 Pretendard를 둔다(HUD 사용자 글꼴은 여전히 패널에 들어오지 않음).
- 선택 메뉴 포털: `document.body` 대신 **패널 안의 포털 자리**로 그린다(패널의 CSS 변수·글꼴·배율 상속). 패널이 없으면 body로 대체.
- Esc 우선순위: 단축키 캡처 > 열린 선택 메뉴 닫기(새로 추가, 이벤트 소비) > 위젯 선택 해제 > 패널 닫기. 기존 앞의 둘·뒤의 둘 동작은 그대로.
- 스크롤: 서랍은 세로 flex, 본문만 `min-height: 0; overflow-y: auto`. 메뉴는 자기 스크롤.
- 섹션: 기존 섹션 id와 펼침 저장을 그대로 쓴다. 일반 탭의 세 묶음은 접히지 않는 묶음 제목(펼침 저장 없음). "모두 펼치기/접기"는 섹션이 둘 이상인 탭에만.
- CSS 범위: 새 규칙은 `.tw-panel` 아래로 한정. `ui-theme.css`의 배너·온보딩용 변수는 지우지 않는다.
- 컨트롤 계약: 스위치는 숨긴(시각적으로만) checkbox로 포커스 유지, 라벨 클릭 한 번에 한 번만 바뀜. 세그먼트는 `role="radiogroup"`/`aria-checked`, 기존 값 그대로 전달. `SliderRow`는 각 슬라이더의 min/max/step/콜백을 그대로 넘긴다.
- 안내문은 줄바꿈 허용(잘라내지 않음). 금색 예외: 주요 버튼(저장 등) 테두리.

## 구현 메모 (2026-11-24)
- Esc(페이지): 위젯 선택 해제 핸들러가 선택 메뉴보다 먼저 window capture에 등록돼 있어, 메뉴가 열린 채 Esc를 누르면 선택이 먼저 풀렸다(브라우저에서 재현). `utils/escapeOwners.ts`가 열린 메뉴·선택된 위젯/묶음을 기록하고, 선택 해제 핸들러는 메뉴가 열려 있으면 양보한다. 패널 닫기 핸들러는 이미 소비된(`defaultPrevented`) Esc를 무시한다.
- Esc(플러그인): 플러그인의 Esc 처리(`WidgetHotkeys.cpp`)는 단축키 캡처 중이 아니면 페이지 상태와 관계없이 `closeSettings()`를 불렀다. 페이지가 Esc를 쓰는 동안(메뉴 열림, 위젯·묶음 선택) `onEscapeOwner('1'/'0')`로 알리고, 플러그인은 그동안 패널을 닫지 않는다. 같은 키 입력에서 페이지가 먼저 Esc를 돌려줄 수 있어 캡처와 같은 300ms 유예를 둔다. 패널이 닫히면 바로 해제한다. 게임 안 동작은 미확인.
- 위젯이 선택된 채 세그먼트 컨트롤에 포커스가 있으면 화살표가 선택지와 위젯 위치를 함께 바꿨다. 키보드 이동은 radiogroup 안 포커스에서 양보한다.
- 행 배치: 라벨과 컨트롤이 한 줄에 안 들어가면(영어의 긴 선택지) 컨트롤을 다음 줄 오른쪽으로 내린다(flex-wrap, 첫 자식이 라벨 칸).
- 빠른 편집 카드: X/Y 위치를 행 둘로 나누고 값은 정수로 반올림해 보인다(저장값은 그대로).
- 시간 표시 선택은 해당 시간 토글 아래 하위 항목으로 들여 쓴다.
- 서랍 바탕 불투명도 0.98(뒤 HUD 글자가 비쳐 안내문이 흐려 보였다).
