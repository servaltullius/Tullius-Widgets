# Compact HUD (A안) 밤샘 구현 계획 — 2026-10-11

## 목표

사용자가 고른 **A안 Tullius Compact**(왼쪽 아래 압축 계기형)를 실제 React/네이티브 위젯으로 구현한다.
품질 기준은 시안(https://claude.ai/artifact/M5QtuhkHoREpGDGTRAmDSh)보다 **훨씬 높아야** 한다.
근거 자료: `docs/plans/2026-10-10-hud-design-reference.ko.md`(4장 A안 스펙, 5장 품질 기준), `docs/plans/2026-10-10-stb-widgets-competitive-research.ko.md`.

## 작업 규칙

- 브랜치 `feat/compact-hud`에서만 작업한다. 작업 단위마다 커밋한다(로컬 커밋만, **push·릴리즈·태그·Nexus 작업 금지**).
- 기존 사용자의 저장된 배치·설정은 깨지면 안 된다. 기존 카드형은 "Classic" 테마로 남기고, Compact는 신규 설치 기본값 + 설정에서 선택 가능하게 한다.
- 위젯은 계속 **항목별 자유 배치**를 지원한다. 띠·슬롯은 기본 배치 프리셋일 뿐이다.
- 각 작업 후 반드시 실행하고 결과를 출력한다: `cd view && npm run lint && npx tsc -b --noEmit && npm test && npm run build`, `node --test scripts/*.test.mjs`.
- 네이티브(`src/`)를 바꾸면 로컬 Windows 빌드로 컴파일을 확인한다(`scripts/release-local.ps1 -NoPublish` 또는 동일한 스테이징 빌드).
- 시각 작업 후에는 Playwright로 `view` 개발 서버(목업 데이터)를 `docs/design/qa-scene-1080p.jpg` 배경 위에서 1920×1080과 3840×2160으로 캡처해 직접 보고 다듬는다. 비교 기준: `docs/design/reference-modpack-hud-1080p.jpg`(모드팩 HUD), 시안 A안.
- 진행 상황은 이 파일 아래 "진행 로그"에 단계마다 기록한다(컨텍스트 요약 대비).
- 매 단계 시작 시 `date`를 출력한다. **07:30 KST 이후면 새 작업을 시작하지 않고 마무리 단계로 간다.**

## 품질 기준 (완료 판정에 사용)

1. 1080p 기본 묶음이 왼쪽 아래 약 480×160px 안에 정돈되고, 4K에서 비례 확대된다.
2. 밝은 바위·눈밭·어두운 배경 모두에서 보조 숫자까지 읽힌다(텍스트 그림자/외곽선, 글자 불투명도는 배경 투명도와 분리).
3. 카드 배경·아이콘 프레임·blur·큰 그림자 반복이 없다. 장비 슬롯만 옅은 받침을 쓴다.
4. 숫자는 고정 폭·정렬, 한국어 긴 장비명·큰 숫자·빈 슬롯에서도 정렬이 흔들리지 않는다.
5. 원값이 다를 때만 원값 표시, 상한·음수는 색+기호로 구분한다.
6. 탐험 중에는 생활 정보·자원만, 전투·변경 시 저항·스탯·장비가 나타나고, 현실 시계·효과 타이머가 다른 항목을 계속 깨우지 않는다.
7. 게임에서 쓸 폰트는 로컬 번들(OFL)로 포함한다(게임 안에서는 Google Fonts에 접속할 수 없다).
8. Prisma 제약(CPU 렌더링, 60FPS)에 맞게 정적 SVG·짧은 opacity 전환만 쓴다.
