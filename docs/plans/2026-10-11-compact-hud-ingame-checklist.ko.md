# Compact HUD 인게임 확인 체크리스트 (1.6.1170)

밤사이 만든 기능 중 **브라우저 목업으로는 확인할 수 없는 부분**(네이티브 수집값, Prisma UI 입력·글꼴)을 게임에서 빠르게 확인하기 위한 순서입니다.
설치: 저장소 루트의 `TulliusWidgets-compact-hud-test-<커밋>.zip`을 MO2 새 모드로 설치(또는 `Data/`에 덮어쓰기) → 게임 완전 재시작.

> 아이템 ID는 콘솔에서 `help "이름" 4`(예: `help "iron arrow" 4`)로 찾은 뒤 `player.additem <ID> <개수>`로 넣으세요. 모드팩마다 이름·ID가 다를 수 있어 ID는 적지 않았습니다.

## 0. 시작 상태
- [ ] 기존 세이브: **클래식 카드 스타일 그대로** 보이는지(배치·표시 항목 유지).
- [ ] Insert → 일반 → HUD 스타일 `컴팩트`로 바꾸면 왼쪽 아래 묶음으로 이동하는지.
- [ ] 글자가 Pretendard(둥근 고딕)로 보이는지. 맑은 고딕처럼 보이면 폰트 로딩 실패(기능에는 지장 없음) → 로그와 함께 알려 주세요.
- [ ] TrueHUD/SkyHUD 자원 바와 겹치지 않는지(묶음 아래 약 25px 여유).

## 1. 장비 슬롯 R / L / Z / P
- [ ] 무기 종류별 아이콘: 한손검·단검·도끼·둔기, 양손검·양손도끼(전투 망치), 활·석궁, 지팡이, 주문(학파별), 방패, 횃불, 맨손.
- [ ] **마법부여 무기**: 슬롯 아래 보라색 충전 바, 20% 미만이면 노란색. 공격력 숫자가 없는 **지팡이**는 20% 미만일 때 `15%` 같은 숫자.
- [ ] **활/석궁**: 오른쪽 위 화살표 + 남은 화살 수, 0개면 붉은색.
- [x] **독**: 무기에 독을 바르면 왼쪽 아래 초록 물방울 + 남은 횟수, 맞힐 때마다 줄어드는지. 같은 무기 두 개를 양손에 들고 한쪽에만 발랐을 때 그 손에만 표시되는지.
  - 2026-10-13 확인: 양손 무기에 각각 바르면 R·L 모두 초록 물방울 `1` 표시, 맞힐 때 줄고 0이면 사라짐, 한쪽에만 바르면 그 손에만 표시.
- [ ] **포효(Z)**: 사용 직후 남은 초(`23s`)와 회복 음영, 단어 점(배운 단어=테두리, 해금=채움). 파워로 바꾸면 아이콘/이름 전환.
- [ ] **물약(P)**: 체력/매지카/스태미나 물약을 마시면 병 색과 `×남은 개수`, 0개가 되면 흐린 병 + 붉은 `×0`. 다른 세이브를 불러오거나 새 게임이면 비워지는지.
- [ ] 장비 이름 표시: 설정 → 장비 → `바꿀 때만`이면 교체 후 3초만 이름.

## 4. 표시 조건 · 편집
- [ ] 기본은 모든 위젯이 항상 보이는지. 한 위젯을 '전투 중 또는 값이 바뀔 때'로 바꾸면 탐험 중에 숨고, 전투 시작 또는 값 변화 시 나타났다가 몇 초 뒤 사라지는지.
- [ ] 위젯 클릭 → 빠른 편집 카드의 `표시 조건` 변경이 저장되는지(재시작 후 유지).
- [ ] 드래그 후 `Ctrl+Z` / `Ctrl+Y`.
- [ ] 프리셋/배치 → 묶음 위치 4곳, 컴팩트 크기 4단계(게임 해상도에서 읽기 편한 크기 확인), 배치 슬롯 저장/불러오기(불러오기는 두 번 눌러 확인).
