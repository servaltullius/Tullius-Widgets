# "지난 날짜" 위젯 (2026-11-25)

툴리우스 채널 요청 순위에서 사용자 글꼴과 자동 숨김 다음이었다. 게임이 시작된 뒤 며칠이 지났는지 보여 주는 위젯이다.

## 사용자 결정 (2026-11-25)
- **표시:** 지난 날 수를 내림해서 보여 준다. 바닐라 통계 화면의 "지난 날"과 같은 값이다(`42일` / `42 days`).
- **도로롱 아이콘:** 기존 73종과 같은 일기장 이모티콘 화풍으로 새 그림을 만든다(Codex 이미지 생성).
- **기본값:** 꺼짐. 새 설치와 기존 사용자 모두 설정에서 켠다.

## 완료 조건과 검증
1. **플러그인:** `RE::Calendar::GetDaysPassed()`를 시간 정보에 `daysPassed`로 보낸다. 값이 유한하지 않거나 음수면 0을 보낸다.
   - 검증: 계약 테스트(수집·JSON 기록), `docs/stats-payload-schema.md` 갱신, 게임 로그와 화면 값.
2. **화면:** `time.daysPassed` 위젯을 클래식과 컴팩트(표준·도로롱) 양쪽에 그린다.
   - 표준 아이콘은 달력 모양으로 하고, 게임 시계와 구별되게 한다.
   - 위젯 목록·설정 토글·빠른 편집·표시 조건·배치 프리셋 위치에 들어간다.
   - 아이콘 팩 키는 `daysPassed`이다.
   - 검증: vitest(렌더링, 값 내림, 설정 병합), 브라우저 확인.
3. **문구와 문서:** 한/영 문구, README 기능 목록, 아이콘 팩 안내의 키 목록, 위젯 수(28 → 29)를 고친다.
4. **도로롱 그림:** `small-daysPassed` 96×96 PNG를 만든다. 기존 그림과 화풍·크기가 맞아야 한다.
   - 검증: 다른 아이콘과 나란히 놓고 직접 확인.
5. **게임 확인:** 위젯을 켜면 바닐라 통계의 "지난 날"과 같은 값이 나오는지 확인한다. 시간을 보내면(대기) 늘어나는지도 본다.

## 결과
- 도로롱 아이콘은 Codex(Sol) 워커가 기존 프롬프트·참고 그림으로 한 번에 그렸다. 게임 시계·현실 시계·플레이 시간 아이콘과 나란히 놓고 확인했다. 생성 기록은 `docs/design/dororong-mini/source/GENERATION_MANIFEST.json`에 있다.
- 처음 배치에서는 누적 플레이 시간 끝과 겹쳐서 위치를 옮겼다.
  - 컴팩트 두 배치: 플레이 시간 오른쪽으로 옮겼다. 네 자리 시간까지 겹치지 않고, 레벨 위젯 왼쪽에 들어간다.
  - 클래식: 카드가 넓어 플레이 시간 아래에 놓았다.
- 2026-11-26 사용자 인게임 확인(DLL md5 `3eeb6b3e196def5bf164e452f966b482`): 위젯 켜기, 바닐라 통계와 같은 값, 대기 후 증가, 도로롱 아이콘과 배치를 확인했다. 로그에 경고는 없었다.
