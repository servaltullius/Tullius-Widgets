[size=4][b]Tullius Widgets[/b][/size]

A modern combat HUD and STB Widgets alternative for Skyrim SE/AE, powered by [url=https://www.nexusmods.com/skyrimspecialedition/mods/148718]Prisma UI[/url].
Since v1.8.0 the cardless [b]Compact HUD[/b] is the default for new installs, and the original card-based Classic style is still available.
Every widget stays independently movable and configurable. Standard icons are the default, and a Dororong icon theme is available as an option.

[size=3][b]New in v1.9.0: icon packs[/b][/size]

[list]
[*]Reskin the Compact HUD with your own PNGs: put files named like [font=Courier New]health.png[/font] or [font=Courier New]slot-sword.png[/font] in [font=Courier New]PrismaUI/views/TulliusWidgets/icon-packs/<pack name>/[/font] and pick the pack in Settings → General → Icon Style
[*]Only the icons you add change; the rest stay built-in, so partial packs work. Packs can be shared as their own mods
[*]How to make one, with every icon name: [url=https://github.com/servaltullius/Tullius-Widgets/blob/master/docs/icon-packs.md]icon pack guide[/url]
[/list]

[size=3][b]v1.8.0 Highlights[/b][/size]

[list]
[*][b]Compact HUD[/b]: a gauge-style cluster in the bottom-left corner that leaves room above vanilla, TrueHUD and SkyHUD resource bars
[*][b]Equipment slots R / L / Z / P[/b]: weapon type and spell school icons with per-hand damage, enchantment charge, doses left of an applied poison, arrows and bolts, shout cooldown and words, and the last potion you drank
[*][b]New widgets[/b]: weather (clear / cloudy / rain / snow / indoors) and total play time
[*][b]Timed effects[/b]: category icons, magnitudes, harmful effects highlighted, filters
[*][b]Per-widget show conditions[/b]: always / in combat / when the value changes
[*]Four corner presets and four sizes for the cluster, three layout slots, layout undo ([b]Ctrl+Z[/b] / [b]Ctrl+Y[/b])
[*]Remappable settings-panel and show/hide keys
[*][b]73 mini Dororong icons[/b] for the Compact HUD (unofficial fan art)
[*]Ships the Pretendard font so the HUD looks the same in game
[*]Removed the screen-edge vignette alerts
[*]Skyrim 1.7.x support; damage reduction now matches the game's calculation
[*]Existing settings keep the Classic style and layout. Switch in Settings → General → HUD style
[/list]

[size=3][b]Core Features[/b][/size]

[list]
[*][b]28 independently positioned HUD items[/b] covering progression, player stats, resistances, defense, offense, equipment, time and weather, movement, and timed effects
[*]Two styles: [b]Compact HUD[/b] and [b]Classic cards[/b]
[*][b]Icon packs[/b]: reskin the Compact HUD with your own PNGs
[*]Uses familiar [b]standard icons by default[/b], with the Dororong theme and optional identifier badges available
[*]Per-widget [b]move, resize, lock, visibility, layer order[/b] and [b]show conditions[/b]
[*]Direct drag editing, neighbor snapping, alignment guides, 1px/10px keyboard movement, and undo
[*]Global opacity and HUD font; color tone and transparent background for the Classic style
[*][b]Preset export/import[/b] and three layout slots
[*]Remappable settings-panel and show/hide keys (ignored while the console or a text field has focus)
[*][b]Runtime warning banner[/b] for unsupported runtime / SKSE / Address Library combinations
[*][b]External JSON localization[/b] support with Korean and English included by default
[/list]

[size=3][b]Displayed Categories[/b][/size]

[list]
[*][b]Progression / Player Info[/b] - Experience progress, Level, Gold, Carry Weight, Health, Magicka, Stamina
[*][b]Resistances[/b] - Magic, Fire, Frost, Shock, Poison, Disease
[*][b]Defense[/b] - Armor Rating, Damage Reduction
[*][b]Offense[/b] - Right/Left Hand Damage, Critical Chance
[*][b]Equipped Slots[/b] - Right/left hand equipment (charge, poison, ammo), Shout/Power (cooldown, words), last potion drunk
[*][b]Movement[/b] - Speed multiplier
[*][b]Time[/b] - Skyrim date/time, real date/time, weather, total play time
[*][b]Timed Effects[/b] - Category icon, effect name and magnitude, remaining duration, filters
[/list]

[size=3][b]Stat Display Notes[/b][/size]

[list]
[*]Critical Chance is shown in the safe range of [b]0% to 100%[/b]
[*]Magic / Fire / Frost / Shock / Poison resistance values are presented with the usual [b]85% cap[/b] in mind
[*]Disease Resist is shown in the safe range of [b]0% to 100%[/b]
[*]Raw values and effective/capped values are separated where useful
[/list]

[size=3][b]Installation[/b][/size]

[b]Manual:[/b] Extract the archive into your [font=Courier New]Skyrim Special Edition/Data/[/font] folder.

[b]Expected layout:[/b]
[code]
Data/
  SKSE/Plugins/TulliusWidgets.dll
  PrismaUI/views/TulliusWidgets/index.html
  PrismaUI/views/TulliusWidgets/i18n/manifest.json
  PrismaUI/views/TulliusWidgets/i18n/en.json
  PrismaUI/views/TulliusWidgets/i18n/ko.json
  PrismaUI/views/TulliusWidgets/assets/...
  PrismaUI/views/TulliusWidgets/fonts/...
[/code]

[size=3][b]Controls[/b][/size]
[list]
[*][b]Insert[/b] - Open / close the settings panel (remappable in Settings)
[*][b]F11[/b] - Toggle widget visibility (remappable in Settings)
[*][b]ESC[/b] - Close the settings panel
[*][b]Drag / Resize[/b] - Edit widgets while the settings panel is open
[*][b]Arrow keys[/b] - Move the selected widget by 1px
[*][b]Shift + Arrow keys[/b] - Move the selected widget by 10px
[*][b]Ctrl + Z[/b] / [b]Ctrl + Y[/b] - Undo / redo layout edits while the settings panel is open
[/list]

[size=3][b]Localization / Translating To Other Languages[/b][/size]

This mod supports [b]external JSON language files[/b].
[b]You do not need to modify the DLL to add another language.[/b]

[b]Included by default:[/b]
[list]
[*]Korean
[*]English
[/list]

[b]Language files are here:[/b]
[code]
Data/PrismaUI/views/TulliusWidgets/i18n/
  manifest.json
  en.json
  ko.json
[/code]

[b]To add another language:[/b]
[list]
[*]Copy [font=Courier New]en.json[/font] and rename it, for example [font=Courier New]fr.json[/font]
[*]Translate the string values in that JSON file
[*]Add a new entry to the [font=Courier New]languages[/font] array in [font=Courier New]manifest.json[/font]
[*]Optionally set [font=Courier New]locale[/font] if you want real-world date/time formatting to follow that language/region
[*]Select the new language from the in-game [b]Language[/b] dropdown
[/list]

[b]Example manifest entry:[/b]
[code]
{
  "code": "fr",
  "label": "Français",
  "file": "fr.json",
  "locale": "fr-FR"
}
[/code]

If some translation keys are missing, the UI falls back to the bundled [b]English[/b] strings instead of breaking.
